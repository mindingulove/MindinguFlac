# Mindinguflac v1.2.8

This release updates Spotify metadata handling and expands the Now Playing experience.

- Updates SpotiFLAC to 3.9.0 at upstream commit `a471fdc`.
- Restores normalized Spotify play counts on artist pages, including after fast sidebar previews.
- Removes duplicate compilation editions from artist Popular Tracks.
- Preserves Spotify's Popular Tracks order instead of applying local taste ranking on artist pages.
- Adds an expandable Now Playing view across the full app above the player.
- Uses a wide 16:9 stage for expanded videos while preserving square audio artwork.
- Adds responsive related music, artist biography, credits, tour, and queue sections to the expanded view.
