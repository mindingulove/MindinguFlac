# Mindinguflac v1.2.3

This release updates the built-in SpotiFLAC download engine to 1.5.2.

- Updated async provider orchestration and current provider integrations.
- Added the browser-backed provider fallback runtime required by the new module.
- Download engines now request identity HTTP encoding to avoid malformed compressed responses on affected networks.
- macOS (Apple Silicon and Intel) and Windows desktop builds are included.
